SUPPLEMENTARY MATERIAL: ORBITAL TRANSFORMATION FOR METALS

The supporting-information PDF describes the electronic representations,
spin constraints, force/stress differences, short trajectories, restart
semantics, and individual calculations. The data repository supplies the
complete scientific inputs and outputs, build provenance, analysis code,
independent matrix verification, and editable figures.

The independent matrix experiment and CP2K calculations are different
kinds of evidence. Matrix checks do not validate a self-consistent Hxc
kernel by themselves. Historical transcriptions are not a substitute for
raw electronic-structure data and are not used for the new tables.

Reproduction instructions are in README.txt and validation-20261018/README.txt.
The source pin and exact dependency/input versions are in machine-readable
manifests. DFT, tblite, and spin-constraint correction builds are identified
separately. Matched pairs use the same executable configuration.

The scope is fixed-number variational consistency and compact solver
validation. No universal speed advantage, asymptotic dense-Hessian scaling
advantage, converged materials prediction, or long-time dynamical stability
is asserted. Generalized-smearing corrections are not physical entropies.
Wavefunction restart initializes new minimizer histories.
